GOLDHOUR — The Halcyon Heist: a top-down stealth heist game. One night inside the Halcyon National Bank: read the patrols, slip the cones, crack the vault, take the Halcyon Star ($10,000) and reach the getaway van. Three guards with sweeping vision cones and suspicion meters, three CCTV cameras, one alarm meter that can lock the whole bank down, twelve prizes worth $32,400, and tools that all cost money — coins, an EMP, a security terminal. Original art, names and sounds; zero libraries, zero network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move, SHIFT to sneak, hold E at the vault wheel or the terminal, SPACE to toss a coin, F for EMP.
